📖 クライアントIDの取得手順
  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を有効化
  3. 「OAuth同意画面」を構成（User type: 外部、テストユーザーに自分のGmailを追加）
  4. 「認証情報」→「OAuthクライアントID」→ アプリの種類 ウェブアプリケーション
  5. 承認済みのJavaScript生成元 にこのアプリのURLを追加
    （例：http://localhost:8766 / 公開後は https://...）
  6. 発行された クライアントID を上の欄に貼り付けて保存
