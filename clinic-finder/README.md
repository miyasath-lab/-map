# 那覇市・南部地区 医療機関検索（静的サイト）

那覇市医師会の医療機関検索（`nahashi.okinawa.med.or.jp/sp/med_search/`）と同じ使い勝手で、
**南部地区（南部保健所管内）まで含めて**探せる検索サイトです。
サーバー不要の静的サイト（HTML + JS のみ）で、検索・絞り込みはすべて閲覧者の端末内で完結します。

## できること

| 機能 | 内容 |
|---|---|
| 🔍 フリーワード | 医療機関名・カナ・住所・診療科・特徴を横断検索（スペース区切りでAND、全角/半角・カナ/かなの揺れを吸収） |
| 📍 地区 | 那覇市／南部（本島）／南部（離島）のグループ単位、または市町村単位で絞り込み |
| 🩺 診療科 | データに含まれる標榜科を件数つきで一覧（多い順） |
| 🕒 今診療中 | 端末の日時と登録された診療時間から、いま開いている施設だけを表示 |
| 🏥 種別・特徴 | 「病院のみ」「人工透析」「在宅医療」「小児対応」「夜間・休日対応」など、データ側のタグで絞り込み |
| 📏 近い順 | 現在地（Geolocation）からの距離順に並べ替え。座標未登録なら市町村中心からの概算 |
| ⭐ お気に入り | 紹介先候補などを端末内に保存 |
| 🔗 URL共有 | 絞り込み条件がURLに入るので、そのまま同僚に送れる |
| 📋 情報コピー | 施設名・住所・電話・診療科をまとめてコピー（紹介状や連絡メモ用） |
| ⬇️ CSV書き出し | 検索結果の一覧をCSVで保存 |
| 📱 PWA | ホーム画面に追加でき、2回目以降はオフラインでも開ける |

## 動かし方（ローカル確認）

```bash
cd kenshu-app
python3 -m http.server 8766
# ブラウザで http://localhost:8766/clinic-finder/ を開く
```

`file://` で直接開くと `data/facilities.json` の読み込みが `fetch` の制約でブロックされます。必ずサーバー経由で開いてください。

## ⚠️ 同梱データについて

`data/facilities.json` に入っているのは **動作確認用の架空データ**（施設名はすべて「サンプル〜」、電話番号は `098-000-xxxx`）です。
実在の医療機関ではありません。公開・運用の前に必ず実データへ差し替えてください。差し替えると画面上部の警告バナーは自動で消えます。

## データの差し替え方

### A. 沖縄県の公開データから作る（推奨）

沖縄県の医療機関情報は、令和6年度以降は厚生労働省の全国統一システム
**「医療情報ネット（ナビイ）」／G-MIS** に集約されており、そのオープンデータが公開されています
（県独自の「うちなぁ医療ネット」は令和6年3月末で終了）。

- 沖縄県 公式ページ：[医療機関・薬局を探すには（ナビイ、G-MIS、医療・薬局機能情報提供制度関係）](https://www.pref.okinawa.jp/iryokenko/iryo/1005807/1006345/1006355.html)
- オープンデータ：[医療情報ネットのオープンデータ（e-Govデータポータル）](https://data.e-gov.go.jp/data/dataset/iryou_teikyouseido_mhlw)

沖縄県分のCSVをダウンロードしたら、次の3ステップで差し替えます。

**① 列の対応づけを確認する**

```bash
cd clinic-finder
node tools/build-facilities.js 沖縄県.csv --encoding sjis --inspect
```

認識した列・未対応の列・1件目の変換結果が表示されます。
取り込みたい列が「未対応」に出ていたら、`csvmap.js` の `FIELD_ALIASES` にその列名を足してください。

**② 変換する**

```bash
node tools/build-facilities.js 沖縄県.csv --encoding sjis --only-nanbu \
  --type "病院|診療所" \
  --source "厚生労働省 医療情報ネット オープンデータ（沖縄県）" \
  --source-url "https://data.e-gov.go.jp/data/dataset/iryou_teikyouseido_mhlw"
```

`--only-nanbu` で那覇市・南部地区（南部保健所管内）だけに絞り込まれ、`data/facilities.json` が書き出されます。
病院・診療所・歯科・薬局が別ファイルに分かれている場合は、複数ファイルをまとめて渡せます。

```bash
node tools/build-facilities.js 病院.csv 診療所.csv -e sjis --only-nanbu --source "..."
```

**③ 確認して公開**

`python3 -m http.server` でローカル表示し、件数・地区の内訳・診療時間の表示を確認してから公開します。
「情報」タブに出典と更新日が表示されるので、`--source` と `--source-url` は必ず指定してください。

#### 対応しているCSVの形

公的CSVは年度・様式で列構成が変わるため、次の揺れを吸収します。

| CSVの形 | 扱い |
|---|---|
| 列名の別名（`医療機関名称` / `施設名称` / `名称` …） | まとめて同じ項目として認識 |
| 住所が `所在地（都道府県）`＋`所在地（市区町村）`＋`所在地（町字・番地）` | 連結して住所にし、市区町村から地区を判定 |
| 市区町村が `島尻郡八重瀬町` のような郡つき表記 | `八重瀬町` に正規化 |
| 診療科目が `診療科目1` `診療科目2` … と横に並ぶ | すべて拾って重複を除去 |
| 診療科目が `内科、循環器内科` のような区切り文字 | `、` `,` `／` `・` で分割 |
| 診療時間が `診療曜日`＋`診療開始時間`＋`診療終了時間` の3列 | 曜日別の診療時間に変換（`0900` `9:00` `9時00分` いずれも可） |
| 診療時間が `月曜日診療時間` … と曜日ごとの列 | 各セルの時間帯を曜日別に変換 |
| 診療時間が `月火水木金 9:00-12:30 14:00-18:00` の自由記述 | 解釈できれば曜日別に変換、できなければ原文を表示 |
| 1施設が複数行に分かれている | `保険医療機関コード`（無ければ名称＋住所）で1件に統合し、診療科目と診療時間を合算 |
| 緯度・経度が無い | 市町村中心の概算座標を使い、詳細画面に「概算」と明記 |

#### コマンドのオプション

| オプション | 意味 |
|---|---|
| `-o, --out <path>` | 出力先（既定 `data/facilities.json`） |
| `-e, --encoding <enc>` | `utf-8`（既定）または `sjis`（自治体CSVは Shift_JIS が多い） |
| `--source <text>` | 出典の表記。アプリの「情報」タブに表示されます |
| `--source-url <url>` | 出典ページのURL（情報タブにリンク表示） |
| `--updated <date>` | 更新日（既定は実行日） |
| `--only-nanbu` | 那覇市・南部地区以外の行を捨てる |
| `--type <正規表現>` | 施設種別で絞る（例 `--type "病院\|診療所"` で薬局を除く） |
| `--merge` | 既存の出力に追記（医療機関コード、無ければ名称＋住所が同じ行は上書き） |
| `--inspect` | 変換せず、列の対応づけだけを表示 |

### B. その場でCSVを取り込む（サイトを再公開しない）

サイトの「🗂 データ」タブからCSVを選ぶと、その端末のブラウザにだけ保存されて検索に使われます。
`⬇️ facilities.json を書き出す` を押せば、そのまま `data/facilities.json` として配置できるファイルが得られます。

## 地区の定義を変える

`csvmap.js` の `REGION_GROUPS`（那覇市／南部（本島）／南部（離島））と `MUNI_LATLNG` を編集すると、
グループの構成も、地区の絞り込みの選択肢も、変換ツールの `--only-nanbu` の判定もまとめて変わります。
中部・浦添まで広げたい場合もここにグループを足すだけです。

## 公開

`clinic-finder/` フォルダをそのまま静的ホスティングに置けば動きます（ビルド不要）。

- **GitHub Pages**：リポジトリの Settings → Pages を `main` / root にすると `https://<user>.github.io/<repo>/clinic-finder/` で公開されます。
- **Netlify Drop**：`clinic-finder` フォルダを [app.netlify.com/drop](https://app.netlify.com/drop) にドラッグ＆ドロップ。

ホーム画面追加とオフライン動作には https が必要です。

## 出典と利用条件について

- 沖縄県の医療機関情報は [沖縄県公式ページ](https://www.pref.okinawa.jp/iryokenko/iryo/1005807/1006345/1006355.html) の案内どおり、厚生労働省「医療情報ネット（ナビイ）」／G-MIS に集約されています。オープンデータの配布形式・更新時期は [e-Govデータポータル](https://data.e-gov.go.jp/data/dataset/iryou_teikyouseido_mhlw) で確認してください。
- 公開データを再掲載する際は、提供元が示す**利用規約（出典表示の要否・加工の可否）**を必ず確認してください。本サイトは `meta.source` / `meta.sourceUrl` を「情報」タブに表示する作りにしてあります。
- 医師会の会員名簿など、提供元が転載を制限しているデータもあります。掲載前に許諾を確認してください。
- 診療時間・休診日は変わりやすい情報です。`meta.updated`（更新日）を必ず入れ、定期的に洗い替えることをおすすめします。

## ご利用上の注意

- 掲載内容は変更されることがあります。受診前に各医療機関へ確認してください。
- 「今診療中」は端末の日時と登録データからの機械的な判定で、臨時休診・祝日・年末年始は反映されません。
- 急を要する症状のときは救急外来の受診または119番通報を検討してください。
